PAYOUTLENS - FOUR SEPARATE SCREENS

Flow: Overview (overview.html) -> Try Demo -> Add Payouts (add-payouts.html) -> Analyse Payouts -> Dashboard (dashboard.html) -> Details (details.html).

Run on Windows:
1. Extract this ZIP.
2. Open the PayoutLens_Multipage_Fixed folder in VS Code.
3. Open Terminal in that folder (the folder containing package.json).
4. Run: npm install
5. Run: npm start
6. Open http://localhost:4173

The Overview page is naturally a long landing page. It is a separate document from Add Payouts, Dashboard and Details. Navigation and the primary demo flow move between separate HTML files. This is a client-side prototype; no server database or account system is included. Internet is needed for remote fonts/images/CDN assets used by the supplied designs.
